# Structure de la documentation — INF1430

Ce dossier est organisé de façon à permettre à un évaluateur de trouver rapidement instructions, livrables, analyses, guides plateformes et retours.

## Vue d'ensemble des dossiers

- [01-project-instructions](01-project-instructions/)
	- Instructions de cours et énoncés des devoirs.
	- Comprend guides d'étude et documents d'instruction officiels.

- [02-deliverables](02-deliverables/)
	- Livrables finaux.
	- Comprend fichiers de rapport et exportations de présentation.

- [03-analysis-and-calculations](03-analysis-and-calculations/)
	- Notes de support — analyses et calculs utilisés pour le projet.

- [04-raspberrypi-guides](04-raspberrypi-guides/)
	- Guides de configuration et validation Raspberry Pi.

- [05-feedback](05-feedback/)
	- Documents de retours des professeurs pour les soumissions précédentes.

- [99-archive](99-archive/)
	- Matériel de planification/brainstorming conservé pour la traçabilité.

## Notes

- Ce README est l'index unique de la documentation du dossier `docs`.
- Les noms de dossiers sont numérotés pour montrer l'ordre de lecture logique.
